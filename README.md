
# C++ Expense Tracker

## Project Overview
The Expense Tracker is a menu-driven command-line application
developed using C++.

It helps users record, manage and calculate their daily expenses.

## Features
1. Add new expenses.
2. View all recorded expenses.
3. Calculate category-wise expenditure.
4. Calculate overall expenditure.
5. Validate user inputs.
6. Handle invalid menu selections.
7. Support multiple expense categories.

## Technologies Used
- Programming Language: C++
- IDE: Visual Studio Code
- Compiler: GCC / JDoodle Online Compiler
- Data Structures: Vector and Map

## C++ Concepts Used
- Variables and data types
- Structures
- Functions
- Conditional statements
- Loops
- Vectors and Maps
- Input validation

## How to Run

1. Open main.cpp in a C++ editor.
2. Compile the source code using a C++ compiler.
3. Execute the generated program.
4. Select an option from the menu.
5. Enter the requested expense details.

## Sample Output

Expense Name: Lunch
Category: Food
Amount: Rs.100

Expense added successfully!

## Limitations
Expense records are maintained in memory
and are cleared when the program exits.
